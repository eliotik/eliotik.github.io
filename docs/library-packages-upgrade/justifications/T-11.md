## 1. Goal recap

Replaced `import { ThemeModeScript } from "flowbite-react"` and `<ThemeModeScript />` in `src/layouts/Layout.astro` with an inline `<script is:inline>` that reads `localStorage.theme` (or falls back to `prefers-color-scheme`) and applies/removes the `.dark` class on `<html>` before first paint — eliminating the dependency on flowbite-react for theme initialization.

## 2. What changed

- `src/layouts/Layout.astro`: Removed `import { ThemeModeScript } from "flowbite-react"` from the frontmatter; removed `<ThemeModeScript />` element; inserted verbatim `<script is:inline>` block before `<ViewTransitions />` in `<head>`.

## 3. Why this approach

This task implements design §1 success criterion 6 ("Dark/light theme toggle works without FOUC") and follows the plan's explicit instruction in §4 #task-t-11 to replace flowbite's `ThemeModeScript` with an equivalent inline script. The verbatim script from the plan was used without modification — no alternatives were considered since the plan is prescriptive.

The site uses a dual theme mechanism (pre-existing, not introduced by this task): `data-theme="dark|light"` on `<html>` drives the site's CSS custom properties (via `toggle-theme.js`, which runs synchronously from `public/` and sets `data-theme`), while `.dark` class was flowbite-react's own dark-mode marker for its components. The inline script preserves the `.dark` class behavior 1:1. T-24 will clean up both the `.dark` side and the flowbite-react dep once it is no longer used anywhere.

The design risk register entry for flowbite dependency removal (T-24 depends on T-11) is the relevant touch point here — this task unblocks T-24 by removing the only usage of `ThemeModeScript`.

## 7. Risks introduced or accepted

The `.dark` class and `data-theme` attribute are both set on `<html>` but by different mechanisms (the new inline script sets `.dark`, `toggle-theme.js` sets `data-theme`). This dual mechanism is pre-existing from before T-11 — flowbite's `ThemeModeScript` was already adding `.dark` while toggle-theme.js set `data-theme`. T-24 will remove flowbite entirely, at which point the `.dark` class side becomes redundant. The inline script will remain harmless until T-24 completes cleanup.
