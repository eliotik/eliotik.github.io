## 1. Goal recap

Added `.github/dependabot.yml` to enable weekly grouped Dependabot updates for npm packages and GitHub Actions, separating major-version PRs from minor/patch updates.

## 2. What changed

- `.github/dependabot.yml` (created): Configures two Dependabot update schedules — one for npm (weekly Monday 09:00 UTC, grouped by ecosystem: astro, react, eslint, tailwind, prod-minor, dev-minor) and one for GitHub Actions (weekly Monday). Both receive the "dependencies" label; GitHub Actions PRs also get "github-actions".

## 3. Why this approach

This task implements design §2 finding 3: "No Dependabot / Renovate. No automated security or stale-dep detection." (Severity: Medium). The Dependabot YAML format (v2) is the GitHub-native solution — no third-party tooling required, no new runtime dependencies, and directly supported by the repository's GitHub Pages hosting environment. Renovate was considered but rejected as it requires a separate service/app installation; Dependabot is zero-config beyond the YAML file. The grouping strategy (ecosystem-specific groups for Astro, React, ESLint, Tailwind + catch-all minor/patch groups) follows the plan's §4 verbatim specification to avoid flooding the PR queue with individual dependency bumps. No risk register entries from design §6 are introduced by this config-only change.
