## 1. Goal recap

Rewrote `src/components/ImageSliderClient.tsx` to use pure CSS scroll-snap instead of the `flowbite-react` `<Carousel>` component, preserving the identical external props API so `ImageSlider.astro` required no changes.

## 2. What changed

- `src/components/ImageSliderClient.tsx` — Removed all `flowbite-react` imports (`Carousel`, `CustomFlowbiteTheme`), removed the `customTheme` constant, replaced the `<Carousel>` wrapper with a plain `<div>` using Tailwind snap-x classes. Added accessible ARIA attributes (`role="region"`, `aria-roledescription`, `aria-label`, `aria-roledescription` on slides), `tabIndex={0}` for keyboard navigation, and `loading="lazy"` / `decoding="async"` on images.

## 3. Why this approach

This task implements design §4 Phase 1 T-10 which mandates replacing `flowbite-react`'s `<Carousel>` with a pure CSS scroll-snap implementation. The exact JSX was specified in the plan §4 step 4 and was copied verbatim. No alternative was evaluated as the spec was prescriptive.

The `flowbite-react` package import is removed from `ImageSliderClient.tsx` but the dependency remains in `package.json` — this is intentional per design §4 T-24 which explicitly owns the dep removal step. Risk R5 from design §6 (dangling `optimizeDeps.include`) is scoped to T-24 which will update `astro.config.mjs`.

The `scrollbar-thin` Tailwind class references the `tailwind-scrollbar` plugin which is not installed. This class is a no-op at this point but is harmless and is specified in the plan verbatim. T-22 (Tailwind 4 upgrade) will determine whether to install the plugin or remove the class.

## 7. Risks introduced or accepted

- The `scrollbar-thin` Tailwind utility class references the `tailwind-scrollbar` plugin which is NOT currently installed in `package.json`. The class is currently a no-op (renders without visible effect). This is acceptable: the class is specified verbatim in the plan, and T-22 (Tailwind 4 upgrade) will determine whether the plugin should be added or the class removed.
- `flowbite-react` import is removed from `ImageSliderClient.tsx` but the `flowbite` and `flowbite-react` packages remain in `package.json`. This is intentional — T-24 owns the dep removal. No code in the codebase now imports from `flowbite-react` via this component (T-11 covers `ThemeModeScript`).
- The new carousel has no previous/next navigation buttons. This is a feature change from the flowbite-react carousel which had arrows. The plan does not specify adding buttons, so this is accepted behavior. Keyboard navigation (arrow keys) and touch swipe (native) are supported.
