## Summary

Prettier (via the formatter pass run as part of T-25) silently stripped backslashes from a code-fence info-string in `src/content/blog/local-coding-model-desktop-macbook.md`, corrupting the rendered code-block title on the published article `/posts/local-coding-model-desktop-macbook/`.

## Reproduction

1. `git checkout upgrade/T-25-ts-toolchain` (commit `f660479`)
2. `pnpm install --frozen-lockfile`
3. Inspect line 91 of `src/content/blog/local-coding-model-desktop-macbook.md`.
4. Diff against the merge-base:

   ```
   git diff $(git merge-base main HEAD)...HEAD -- 'src/content/blog/local-coding-model-desktop-macbook.md'
   ```

5. Build and grep the rendered HTML:

   ```
   pnpm build
   grep -n "wslconfig" dist/posts/local-coding-model-desktop-macbook/index.html
   ```

## Expected behavior

Per the T-25 task spec and §2 of the dev's justification:

> "77 source files: auto-format reflow by Prettier (whitespace/indentation normalization; **no semantic changes**)."

And per the QA prompt's pass criteria:

> "the 77 reformatted files (**whitespace only**)."

Markdown content — including the info-string of fenced code blocks (e.g. `` ```ini title='…' ``) — must not be altered by a formatter pass.

## Actual behavior

Prettier interpreted the backslashes inside the single-quoted `title=` attribute on a fenced code block as character-class escapes and stripped them. The on-disk source line changed:

```
- ```ini title='C:\Users\<me>\.wslconfig' showLineNumbers=false
+ ```ini title='C:\Users<me>.wslconfig' showLineNumbers=false
```

The corruption is user-visible in the rendered article: the `<figcaption>` of the WSL-config code block on `/posts/local-coding-model-desktop-macbook/` now reads `C:\Users<me>.wslconfig` instead of `C:\Users\<me>\.wslconfig`. The inline-code occurrence on line 89 (between backticks) is unaffected because prettier does not reformat inline-code spans.

The published article was about WSL networking; an incorrect path-with-stripped-backslashes in the figure title is materially wrong content.
